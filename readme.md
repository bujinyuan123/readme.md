# 猜数字小游戏

一个用 Python 编写的命令行小游戏：电脑随机出一个 1-100 的整数，你来猜，程序会提示"大了"或"小了"，直到猜中为止，并统计一共猜了几次。

## 项目结构

```
first/
├── guess_number.py   # 游戏主程序（单文件）
└── readme.md         # 项目说明文件（本文件）
```

## 环境要求

- 需要安装 Python 3（本程序在 Python 3.13 下测试通过）
- 无需安装任何第三方库

## 如何运行

### 方式一：命令行运行（推荐）

1. 按 `Win + R`，输入 `cmd`，回车打开命令提示符
2. 切换到项目目录：

   ```bash
   cd D:\play_do\first
   ```

3. 运行程序：

   ```bash
   python guess_number.py
   ```

4. 按照提示输入 1-100 之间的整数，猜中后游戏结束，会显示你猜了几次。

### 方式二：直接双击运行

也可以直接双击 `guess_number.py` 文件，在弹出的窗口中游玩。

## 程序逻辑说明

```python
import random                  # 导入随机模块
answer = random.randint(1, 100) # 电脑随机生成 1-100 的答案
count = 0                       # 记录猜测次数

while True:                    # 无限循环，直到猜中
    guess = int(input("..."))   # 让用户输入猜测
    count += 1                  # 次数 +1
    if guess < answer:         # 猜小了 → 提示"小了"
        print("小了，再大一点！")
    elif guess > answer:       # 猜大了 → 提示"大了"
        print("大了，再小一点！")
    else:                      # 猜中 → 结束循环
        print("恭喜你，猜中了！")
        break
```

核心思路：用一个 `while True` 循环不断让用户输入，每次比较输入值和答案，根据大小关系给出提示；猜中后用 `break` 跳出循环。
