# 猜数字小游戏

这是通识任务 2 的作业，用 Python 写了一个猜数字的小游戏。电脑随机想一个 1 到 100 的整数，我输入猜测，程序提示“大了”还是“小了”，猜中后告诉我一共猜了几次。

整个程序只有一个 py 文件，也没有用第三方库，装好 Python 就能跑。

## 运行方法

按 `Win + R`，输入 `cmd` 回车，然后执行：

```bat
cd /d D:\play_do\first
python guess_number.py
```

这里要加 `/d`。如果只写 `cd D:\play_do\first`，在 C 盘打开的 cmd 里其实不会切到 D 盘。

运行后按提示输入 1-100 的整数。想提前退出可以按 `Ctrl + C`。

## 文件说明

- `guess_number.py`：游戏代码
- `readme.md`：这个说明文件

## 代码思路

程序主要分三块：

1. 用 `random.randint(1, 100)` 生成答案。
2. 用 `while True` 循环让玩家一直猜，`count` 记录次数。
3. 每次拿猜测值和答案比较：小于答案提示“小了”，大于答案提示“大了”，相等就输出答案和次数，再用 `break` 结束。

输入部分单独写在 `get_guess()` 里。它会去掉首尾空格，再用 `int()` 转成整数。如果输入的不是整数，会捕获 `ValueError` 让玩家重输；空输入和不在 1-100 范围内的数字也会被拦下来。这些无效输入不会增加猜测次数。

## 运行效果

假设答案是 62：

```text
===== 猜数字小游戏 =====
电脑已经想好了一个 1-100 的数字，你来猜猜看。
请输入你猜的数字（1-100）：50
小了，再猜大一点。
请输入你猜的数字（1-100）：75
大了，再猜小一点。
请输入你猜的数字（1-100）：62
猜对了，答案就是 62。
你一共猜了 3 次。
```
